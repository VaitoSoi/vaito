# my personal site :D

This is a simple personal site, built with plain HTML, CSS and JS.

I use a AI at the CSS part since my brain just too smol for doing CSS on my own :(

**Note:** I haven't implemented the responsive UI yet, sorry :(

## Run this project

### a. In dev mode:

Run this command in your terminal

```bash
npm run dev
```

### b. In production:

Run this build command:

```bash
npm run build
```

Then serve it:

```bash
npx serve dist
```
